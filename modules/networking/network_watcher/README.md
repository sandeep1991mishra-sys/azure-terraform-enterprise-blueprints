# Azure Network Watcher Module
# 
# Overview
# 
# This Terraform module creates and manages Azure Network Watcher resources for network monitoring and troubleshooting.
# 
# Features
# 
# Supports multiple Network Watcher configurations using for_each.
# 
# Configurable resource name, Resource Group, and Azure region.
# 
# Supports optional resource tags.
# 
# Exposes resource IDs, names, locations, and Resource Group names.
