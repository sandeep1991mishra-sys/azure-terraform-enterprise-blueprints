# Azure Virtual Network Manager Module
# 
# Overview
# 
# This Terraform module creates Azure Virtual Network Manager resources to centrally manage network connectivity and security # policies across supported Azure subscriptions and management groups.
# 
# Features
# 
# Supports multiple Network Managers using for_each.
# 
# Configurable Azure region and Resource Group.
# 
# Supports subscription and management group scopes.
# 
# Configurable network-management capabilities.
# 
# Supports optional resource tags.
# 
# Exposes resource IDs, names, locations, and Resource Group names.
